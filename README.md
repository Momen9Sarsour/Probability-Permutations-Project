# 📌 ** Probability & Permutations Project (Java)**

# Probability & Permutations Calculator – Java

A Java mathematics tool designed to calculate probability, permutations, factorials, combinations, and related probability operations.

---

## 🎯 Project Goal

This project was built for the Mathematics course (Probability & Statistics).  
It computes **permutations, arrangements, probability values**, and more.

---

## 🚀 Features

### 📌 Permutations (nPr)
Calculates arrangements of objects using:
P(n, r) = n! / (n - r)!

### 📌 Factorial Calculation  
Used for all probability operations.

### 📌 Basic Probability  
Solves simple probability problems based on user input.

### 📌 User-Friendly Console Menu  
Interactive menu that guides the user through probability operations.
